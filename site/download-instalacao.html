Download & Instalação

Baixe os arquivos e siga o passo a passo para colocar seu time no ar.

Instale com um comando só

Cola isso no terminal e o instalador faz tudo automaticamente. Ele vai perguntar sobre sua empresa e configurar os 20 agentes em menos de 5 minutos.

20 agentes 6 squads CLAUDE.md empresa.yaml install.sh
curl -fsSL https://raw.githubusercontent.com/lucasvalerio10/squads/main/squads/install.sh | bash

Instalação

Siga os passos abaixo. Leva menos de 10 minutos.

1

Instalar o Git

Baixe em git-scm.com e instale com as opções padrão. Depois abra o Git Bash para os próximos passos.

Já vem instalado no Mac. Se precisar, execute no Terminal:

xcode-select --install
2

Instalar o Node.js

Acesse nodejs.org, baixe a versão LTS e instale normalmente. Verifique com:

node --version
3

Instalar o Claude Code

Abra o terminal e execute:

npm install -g @anthropic-ai/claude-code
4

Instalar os Squads

Windows: use o Git Bash · Mac: use o Terminal

curl -fsSL https://raw.githubusercontent.com/lucasvalerio10/squads/main/squads/install.sh | bash

O instalador vai fazer perguntas sobre sua empresa e criar o arquivo empresa.yaml automaticamente.

5

Abrir o Claude Code

Abra o terminal em qualquer pasta do seu projeto:

claude
6

Fala o que você precisa

Não precisa decorar nenhum comando. Só descreve o problema em português mesmo, tipo:

"preciso montar minha estratégia da semana" · "quero criar uma proposta comercial" · "me ajuda a escrever um anúncio"

O agente certo entra em ação sozinho.

7

Pronto, seu time está no ar

O Claude já sabe quem é sua empresa, o que você vende e pra quem. Cada resposta vai ter o contexto do seu negócio, não uma resposta genérica de internet.

Daqui pra frente é só usar.
